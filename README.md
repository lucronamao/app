# Lucro na Mão

Aplicativos da lojinha: controle de vendas, divulgação e precificação.
Rodam no navegador do celular, sem instalar nada e sem mensalidade.

- `hub.html` — menu dos apps (página inicial)
- `index.html` — Controle da Lojinha
- `divulga.html` — Divulga na Mão
- `precificacao.html` — Precificação na Mão

Conteúdo estático, sem servidor e sem banco de dados. Os dados de cada usuária
ficam no próprio aparelho dela.
